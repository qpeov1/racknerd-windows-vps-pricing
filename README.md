## 下单前必须知道的四条限制

这部分是条款和帮助文档里的内容，套餐页上不会主动告诉你，但每一条都可能影响决定。

**1. 默认不退款。** RackNerd 条款原文是按个案处理退款，默认付款后不退，也没有试用期。换句话说，下单就当钱花出去了。取消需在续期前 7 天通过客户端提交书面通知，取消后数据会被删除；降级要提前 5 天申请。

**2. 默认无管理（unmanaged）。** 官方支持范围限于底层基础设施——硬件、电力、网络、可用性，24 小时工单响应，这部分免费。系统配置、防火墙、软件排障、恶意代码清理都不在服务范围内。你会配 Windows Server 就没问题；不会的话，要么先学，要么另找 managed 服务商。

**3. 没有自动备份和快照。** 控制面板提供开关机、重装、控制台和重置，没有快照、自动备份，也没有 API 和按小时计费。重要数据从第一天起就要自己规划备份，比如定期下载到本地或另一台机器。

**4. 无正式 SLA。** RackNerd 没有发布带赔偿条款的正常运行时间保证。挂个机器人、挂个工具没人在意几分钟宕机，但如果你要跑的是停一小时就亏钱的业务，这个短板要认真掂量。
